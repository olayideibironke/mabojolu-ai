## Phase 2B evaluation architecture

1. `generalization-harness.ts` externally scores each action and optionally calls `agent.onOutcome` with the actual action, observation, reward, success, and terminal flag.
2. `consequence-grounded-learning.ts` retains per-session consequences, rejects mismatched actions and nonfinite rewards, and chooses a safe alternative after negative feedback where available.
3. `consequence-grounded-evaluator-agent.ts` uses externally delivered outcomes to advance the learning session between actions.
4. `kernel-gated-recovery-agent.ts` uses the actual frozen integrated kernel for initial discovery and post-inspection approval, then uses the separate Phase 2B learning session for strategy recovery.
5. Terminal failures remain failures; model-set failures can cause abstention. No success is credited merely for requesting an experiment.

**Attribution boundary:** Recovery is implemented by the Phase 2B adapter and session, **not** by an independently self-modifying or generally learning frozen v1.42 kernel.

## Known limitations and next research program

- Controlled, repository-authored tasks; no independent external evaluator, real-world hidden task suite, or adversarial transfer study.
- Candidate actions, strategy utilities, and experiment models are provided, limiting discovery claims.
- The frozen kernel's internal planning cycle is not continuously updated by external feedback; the recovery session is separate.
- The evaluation-only adapter has no evidence of persistent cross-process learning or safe online deployment.
- The session treats an externally supplied `success: true` as satisfying objective signals by default when explicit observed signals are absent. This is a trust contract with the evaluator, not independently verified semantic evidence.
- Tests cover targeted success/failure paths, not a statistically powered distributional improvement claim.
- Image-generation quality work was previously parked; Phase 2 does not change that status.

**Future research:** independent held-out environments, blinded benchmark authorship, out-of-distribution tests, comparison against simpler baselines, persistence/rollback tests, safety evaluations, and genuine online kernel-feedback integration. These are future research directions, not unfinished obligations of the closed Phase 2 controlled-evaluation milestone.
